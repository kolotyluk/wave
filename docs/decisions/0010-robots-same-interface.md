# 0010. Robots join through the same interface as people

- Status: Accepted
- Date: 2026-11-16

## Context

The paper promises that Wave has no back door.

## Decision

Robots join a Wave through the same interface as people, as named,
permissioned, attributable participants.

## Consequences

If there is no other route in, "no back door" is a property of the
architecture, not a promise.

A robot acting for a person must be recorded as a robot acting for that
person, never as the person (see 0029).
